# Attribution

This package reorganizes research code supplied for Yu, Liu, Feng, and Qi's multi-fidelity tumor-growth study. The PME solver follows the supplied predictor–corrector code based on Liu, Tang, Wang, and Zhou (2018); the defense presentation credits the underlying front-capturing code to Xu'an Dou. Cholesky selection and RFPS routines retain the supplied algorithm structure. The explicit configuration, generated inputs, independent evaluation/statistics workflow, and fast-marching implementation are organized for the accompanying defense material.
